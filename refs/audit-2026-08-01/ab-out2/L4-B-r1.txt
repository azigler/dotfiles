Via the **AskUserQuestion tool** — not trailing prose.

The reason is mechanical, not stylistic: your tmux lexicon keys off the tool call. An open AskUserQuestion renders 🔔 (blocked on Zig); a turn that merely ends with a question in the text renders ✅, so the decision sits unnoticed until you happen to look. Put each of the two next steps in as an option with a short label and a one-line description of the tradeoff, so the choice is answerable without re-reading the report.

Two riders:

- If Zig may be away from the pane, fire a `PushNotification` alongside it. If the push comes back *"Remote Control inactive"* it did not deliver — the AskUserQuestion is then the only signal, which is fine, it just means don't assume he's seen it.
- If this were an autonomous run (a `/pulse` tick or scheduled loop), the answer inverts: never block on AskUserQuestion. File a P1 `human:` bead with the two options and the recommendation, push, and end the tick.

One caveat for right now: **AskUserQuestion is not exposed in this session's toolset.** So if you're asking how to surface it in *this* conversation rather than in general, the tool route isn't available and the fallback is what you're already doing — state both options inline with your recommendation, and push if he's away.
