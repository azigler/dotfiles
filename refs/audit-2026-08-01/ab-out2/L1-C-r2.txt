Confirmed from the CLI itself:

```
--effort <level>    Effort level for the current session (low, medium, high, xhigh, max)
```

Three ways to get to max:

**1. Right now, mid-session** — `/config`, then set the Effort field to `max`. This applies to the rest of this session, so you can flip it before the research task and back down after.

**2. At launch** — `claude --effort max`

**3. Persist it** — add `"effort": "max"` to `~/.claude/settings.json` so every session starts there. I'd skip this one unless you want max on everything; it's a meaningful cost/latency increase on trivial turns.

For a search-heavy research task, note that effort governs reasoning depth per turn, not how many searches I'll run. If you want breadth too, say so explicitly in the prompt ("search widely, follow citations, don't stop at the first good source") — that moves the needle more than effort alone for a task that's mostly retrieval.
